# Статистика

Раздел: `/statistics/`. Доступ без авторизации, как согласовано для первой версии.

1. Откройте «Загрузить файл», выберите текстовую выгрузку AFTN или AMHS.
2. Проверьте период и счётчики. Новым каналам назначьте существующего абонента или введите название нового и его категорию. Для нескольких каналов одного нового абонента используйте одинаковое название.
3. При повторе месяца подтвердите полную замену выбранного типа. Данные второго типа сохраняются.
4. На странице отчётов выберите месяц, тип, категорию и абонентов. Меню «Печать» и «Скачать» доступны для месячного отчёта с данными. Итоги объединяют выбранные каналы AFTN и AMHS.
5. Названия, категории и привязки меняются в «Абоненты и каналы». Изменения действуют для прошлых месяцев.

AFTN идентифицируется по восьмизначному маршруту, AMHS — по системному имени. Для нового канала можно выбрать абонента из подсказок по имени.

## Установка и проверка

Используйте Python-окружение проекта. Установите зависимости из `begining/requirments.txt`; для Excel используется openpyxl 3.1.5. Печать выполняется в браузере.

Перед миграцией сохраните резервную копию SQLite (при работающем сервере используйте SQLite backup API).

```powershell
python begining/manage.py migrate traffic_stats
python begining/manage.py test traffic_stats
python begining/manage.py runserver
```

Миграция создаёт только новые таблицы. Для отката схемы: `python begining/manage.py migrate traffic_stats zero` — удаляет всю сохранённую статистику и её справочники. Выполнять до отката кода и только после резервного копирования. Git откат не восстанавливает базу.

Исходный текст последней выгрузки каждого типа за месяц хранится в ImportBatch; замена удаляет предыдущую версию. Лимит файла — 5 МБ. Диаграммы и версии отчётов в первую версию не входят.

## Удаление ошибочных данных

В Django Admin доступны удаление одной записи и действие «Удалить выбранные» с подтверждением, при наличии соответствующих прав. Удаление загрузки отчёта удаляет все её строки; абоненты, каналы и другие отчёты сохраняются. Удаление отдельной строки сохраняет загрузку и её исходный текст, но исключает строку из расчётов и экспорта. Для восстановления полного отчёта загрузите исходный файл повторно.

Строка «ИТОГО» в старых AFTN-выгрузках игнорируется и исключается из сохраняемого текста новых загрузок. Файлы без неё поддерживаются. Итоги рассчитываются по каналам.

## Каналы и периоды

Логический номер AFTN хранится числом в канале (079 → 79), обозначение передачи берётся из столбца «Обозначение». При повторной загрузке эти характеристики обновляются; пользовательское имя сохраняется. У AMHS номер пустой.

Строка статистики содержит счётчики, отчётный месяц и ссылки на канал и импорт. Фактическая дата загрузки хранится только в ImportBatch.imported_at.

Загрузка по-прежнему принимает один полный месяц. После загрузки в отчёте можно выбрать один месяц или включительный диапазон месяцев, в том числе через границу года. Пустой конец означает тот же месяц. За диапазон значения суммируются по каналам; обычная XLSX-выгрузка использует ту же выборку. Выборка модели: Record.objects.for_period(start_month, end_month).

Миграция 0004 переносит номер/обозначение из последних загруженных записей в канал, дату — из загрузки, затем удаляет дублирующие текстовые поля записи. Обратная миграция восстанавливает их из текущей карточки канала, без исходных ведущих нулей и исторических вариантов названий; для точного восстановления используйте резервную копию.

## Формат файлов

Первая непустая строка обязательна и содержит `AFTN` либо `AMHS`.

AFTN: вторая строка `01.05-31.05 2026`, далее строки из шести полей: номер; обозначение ПРД; маршрут; название; общее ПРМ; общее ПРД.

AMHS: вторая строка `01.10.2026-31.10.2026`, далее системное имя; общее ПРМ; общее ПРД.

Принимается полный календарный месяц, в кодировке UTF-8 (с BOM или без) или Windows-1251. Служебные счётчики исключены из модели, импорта, сайта, админки и экспортов миграцией 0007; значения общих ПРМ/ПРД сохраняются. Файлы без маркера типа или с лишними полями отклоняются.

С миграции 0005 отчётный месяц хранится непосредственно в Record.report_month с индексом. Он заполняется из периода файла при загрузке; существующие записи получают месяц из ImportBatch. Выбор диапазона использует индекс report_month без соединения с таблицей загрузок для отбора периода. ImportBatch.imported_at хранит фактическую дату загрузки. В БД месяц представлен первым числом месяца, в админке показывается только месяц и год.

## Календарь периода

Фильтры используют Air Datepicker 3.6.0: локальные JS/CSS и MIT-лицензия в static/traffic_stats/vendor/air-datepicker-3.6.0, источник и контрольная сумма указаны в SOURCE.txt. CDN, npm-сборка и дополнительные Python-пакеты при запуске не требуются.

Поле «Период» выбирает месяцы и диапазоны между годами. Один выбранный месяц отправляет одинаковые month/end_month; два — включительный диапазон. Передача YYYY-MM строится через локальные getFullYear/getMonth, без UTC. Кнопка «Очистить» удаляет выбор, пустой период блокирует отправку. Выбор не запускает отчёт автоматически.

Календарь подключается только при открытых фильтрах (?filters=1). При выключенном JS или недоступной библиотеке сохраняются исходные два поля месяцев. Остальные фильтры, последняя статистика и экспорт работают как раньше.

## Вывод по категориям

Порядок категорий отчёта: Федеральные, Международные, Региональные, Локальные, Прочее. В каждой категории единая таблица AFTN/AMHS; каналы одного абонента объединяются под его суммарной строкой. Пустые категории не выводятся. Заголовки: Центр/Абонент, Принято, Передано, Адрес; «Абонент» используется для локальных и прочих.

У одного канала адрес показан в строке абонента. У нескольких каналов строка абонента содержит сумму, под ней строки каналов с пустым первым столбцом и адресами. Итог категории считается только по суммарным строкам, без повторного учёта подстрок. Название берётся из Subscriber.name. Обычная XLSX-выгрузка использует те же строки и итоги.

Миграция 0008 переименовывает Channel.system_name в route_address («Адрес»), сохраняя значения, связи и уникальность пары тип/адрес.


## Пользовательские корректировки

В отчёте за один месяц значок «Редактировать» в строке категории включает поля «Принято» и «Передано». У абонента с несколькими каналами изменяются только строки каналов. Галочка справа от изменённого поля сохраняет это поле; суммы абонента и категории пересчитываются после успешного сохранения. Enter сохраняет, Escape возвращает сохранённое значение. За диапазон месяцев редактирование недоступно.

Миграция 0009 добавляет Record.user_received и user_sent: NULL означает исходный счётчик, 0 — явную корректировку до нуля. Импортированные received/sent сохраняются. Возврат к исходному числу снимает корректировку. Отчёт и Excel суммируют скорректированные значения, включая отчёты за диапазон. Подсказка числа в месячном отчёте показывает исходное значение. Если другой пользователь уже изменил это поле, сохранение отклоняется с просьбой обновить отчёт. При замене импорта существующим механизмом старые записи вместе с корректировками удаляются.

Иконки размещены локально в static/traffic_stats/icons, источники указаны в SOURCES.txt; ссылки атрибуции находятся под отчётом. Стили и скрипт редактора ограничены статистикой. Для сохранения требуется JavaScript; без него сохраняется просмотр и экспорт.

Рядом с сохранённой корректировкой появляется значок возврата с подсказкой «Прежнее значение: N. Вернуть». Нажатие восстанавливает импортированное число и пересчитывает суммы. Во время ввода нового значения это место занимает галочка сохранения.

При просмотре скорректированного месячного отчёта отображается значок информации с исходным числом в подсказке. При включении редактирования он заменяется значком возврата.

С миграции 0010 удаление канала в админке (включая массовое) удаляет связанные строки статистики за все месяцы, вместе с пользовательскими корректировками. Страница подтверждения показывает связанные записи; абонент, загрузки и статистика других каналов сохраняются.

В предпросмотре загрузки поле нового абонента показывает до 20 совпадений по части имени без учёта регистра. Выбор мышью или стрелками и Enter подставляет существующее имя и его тип, не создавая дубль. Пока имя точно совпадает с существующим абонентом, его тип недоступен для изменения в форме импорта. При выключенном JavaScript остаются стандартные подсказки datalist.


## Абоненты и каналы

Раздел показывает каналы в единой таблице: адрес, абонент, категория абонента, тип AFTN/AMHS. Поиск в тулбаре ищет по адресу, названию канала и имени абонента без учёта регистра. Отдельной формы создания абонента нет.

Карандаш включает редактирование привязки канала к абоненту, галочка сохраняет. Можно выбрать существующего абонента через подсказки либо ввести новое имя и категорию. Категория существующего абонента и тип канала не изменяются. Новое имя создаёт абонента и переводит только выбранный канал к нему, без переименования остальных абонентов или каналов. Статистика сохраняет связь с каналом и в отчётах относится к его текущему абоненту. Для редактирования нужен JavaScript. Устаревшая привязка при одновременном редактировании отклоняется.

При каждом открытии страницы загрузки GET-запросом несохранённый предпросмотр очищается из сессии. Загруженный файл остаётся на экране после POST-проверки и при ошибках сохранения, чтобы можно было исправить ввод. После ухода и повторного открытия файл нужно загрузить заново; уже сохранённая статистика не меняется.


## Абоненты без каналов

Абонент создаётся в одной транзакции с привязкой канала через импорт или редактирование строки канала. Отдельное создание в админке отключено. Удаление последнего канала, в том числе массовое в админке, удаляет абонента вместе с его карточкой и комментарием. В подтверждении удаления канала такой абонент перечислен отдельно. При переносе последнего канала прежний абонент удаляется; если другие каналы остались, карточка сохраняется. Очистка выполняется в той же транзакции, поэтому откат возвращает и канал, и абонента. Наличие статистики не влияет на эту проверку.

Миграция 0011 однократно удаляет существующие карточки без каналов. Обратный запуск миграции не восстанавливает удалённые данные: для восстановления используется резервная копия. Произвольные скрипты ORM должны создавать Subscriber и Channel в одной транзакции и после прямого QuerySet.update привязки вызывать lifecycle.delete_unused_subscribers для прежних абонентов. Штатные формы сайта и админки это учитывают.

В меню статистики доступны «Статистика», «Загрузить статистику», «Абоненты и каналы». Отдельная форма «Отчёты» с расширенными фильтрами удалена. Выбор периода теперь находится в тулбаре единой страницы статистики; сформированные таблицы и экспорт сохранены. Старые ссылки ?filters=1 перенаправляются на эту страницу с сохранением периода.

Для месячной статистики с данными под заголовком по центру есть кнопка «Печать» с меню: «Центры - согласование», «Абоненты - рассылка», «Каналы», «Распечатать все». «Центры - согласование» открывает лист «для согласования» из Excel-шаблона в отдельной вкладке и вызывает диалог печати браузера. Все пункты печати подключены. Значок Bootstrap Icons printer размещён локально в SVG вместе с MIT-лицензией, кнопка по высоте совпадает с «Показать» (35 px).

Рядом с печатью находится меню скачивания с пунктами «Файл для экономистов» и «Скачать все». Иконка Bootstrap Icons box-arrow-down размещена локально в SVG вместе с MIT-лицензией. Высота кнопки 35 px. «Скачать все» формирует месячную книгу по шаблону; «Файл для экономистов» скачивает только листы «Каналы ПД», «ФГУП ГК», «Сторонние» (download=economists). При открытии одного меню другое закрывается.

## Скачивание месячной книги по шаблону

«Скачать все» в меню возле заголовка формирует Статистика_месяц_год.xlsx за один месяц (например, Статистика_октябрь_2026.xlsx; download=all). Шаблон хранится в excel_templates/template.xlsx; исходный файл пользователя не изменяется. Сервер использует уже имеющуюся зависимость openpyxl, дополнительные библиотеки для запуска не нужны.

Листы: «для согласования» — федеральные абоненты и принято; «Каналы ПД» — федеральные и международные; «ФГУП ГК» — региональные; «Сторонние» — локальные; «для Оператора» — суммы по абонентам для каналов с флажками рассылки. В первых четырёх листах абонент занимает одну строку с суммой по всем его каналам AFTN/AMHS. Непустые адреса каналов перечисляются в одной ячейке. Пользовательские корректировки учитываются, нулевые значения сохраняются. Категория «Прочее» не входит в первые четыре таблицы, но может присутствовать на листе оператора.

Шапки, подписи и оформление берутся из шаблона; строки расширяются по данным, формулы итогов и ссылки обновляются и пересчитываются Excel при открытии. Метки и правила операторского листа описаны ниже. Все пункты меню печати подключены.

## Адреса и настройки рассылки

В справочнике «Канал» показывает Channel.name, «Адрес» — редактируемый route_address, «Тип» — неизменный AFTN/AMHS. После типа идут флажки рассылки ПРМ/ПРД и адреса рассылки. Флажки mailing_received и mailing_sent по умолчанию выключены. Поле mailing_addresses хранит произвольный текст со списком адресов; при создании канала оно заполняется route_address. Миграция 0012 так же заполняет адреса существующих каналов. После изменения route_address адреса рассылки сохраняют своё значение и редактируются отдельно.

Категорию существующего абонента теперь можно менять в справочнике; она относится ко всем каналам этого абонента. При выборе другого абонента сначала подставляется его категория, после чего её можно изменить. В форме загрузки прежняя блокировка категории существующего абонента сохранена. При сохранении строки проверяются актуальность исходных полей и уникальность адреса в пределах AFTN/AMHS. Настройки только сохраняются: отправка сообщений этой правкой не реализуется.

Адрес в справочнике расположен первым содержательным столбцом и поддерживает сортировку по возрастанию/убыванию (также используется по умолчанию). Название канала и абонент сохраняют свою сортировку. Имя абонента и поле его ввода выровнены вправо. С миграции 0013 mailing_addresses — CharField длиной до 200 символов, в интерфейсе это однострочный input без возможности растягивания. Ограничение проверяется и сервером; значения не обрезаются. Если до миграции найдутся строки длиннее 200 символов, она остановится до изменения данных.

В таблице загрузки первый содержательный столбец — «Адрес», следующий — «Канал» (сохранённое имя известного канала или имя из файла для нового). Адрес можно изменить только у нового AMHS-канала; пустые адреса, значения длиннее 200 и дубли в одном файле/среди существующих AMHS отклоняются без частичного сохранения. При ошибках введённые адреса остаются в предпросмотре.

Новый канал локального абонента получает mailing_received=True, mailing_sent=False и адрес рассылки, равный сохраняемому адресу канала. Для известных каналов настройки рассылки не изменяются. После уточнения AMHS-адреса повторный импорт сначала ищет точное совпадение адреса, затем — точное и единственное совпадение имени AMHS из файла с Channel.name. По неоднозначному имени канал не выбирается, а попадание двух строк в один канал отклоняется.

Адрес нового AMHS при загрузке всегда пустой, пока пользователь его не введёт. В AMHS-файле первое поле считается именем канала, не адресом; поиск существующих AMHS ведётся исключительно по точному Channel.name. Совпадение имени из файла с чужим route_address не используется. При неоднозначном имени сохранение блокируется с просьбой уточнить справочник. Адрес AMHS допускается пустым, в том числе у нескольких разных каналов; непустые адреса по-прежнему уникальны внутри типа. Для AFTN адрес обязателен и поиск остаётся по нему. Миграция 0014 меняет ограничения, не очищая ранее сохранённые адреса. Пустой адрес означает также пустой адрес рассылки при создании; в Excel пустые адреса не добавляют лишние разделители.

В столбце «Канал» экранной статистики и обычного Excel-экспорта для AMHS используется Channel.name, для AFTN — route_address. Правило одинаково для одиночной строки абонента и подстрок нескольких каналов. Шаблонная книга «Скачать все» сохраняет фактические адреса в своих столбцах «Адрес».


## Метки обновлённого Excel-шаблона

Экспорт «Скачать все» заполняет текущий excel_templates/template.xlsx по меткам, а не по фиксированным номерам строк. Сохраняются названия и порядок листов, шапки, подписи, стили, ширины, объединения и области печати. Исходный шаблон не изменяется. #месяц и #год заменяются и отдельно, и внутри текста. Категориальные метки (#федеральный/#федеральные, #международные, #региональные, #локальный) задают повторяемые строки итогов по абонентам. #user_received и #user_sent — итоговые значения с учётом корректировок; #route_address — список непустых адресов каналов абонента.

На листе оператора #абонент задаёт одну строку на абонента с хотя бы одним каналом с флажком рассылки. «Принято» суммируется только по каналам с флажком ПРМ, «Передано» — только с флажком ПРД; учитываются пользовательские корректировки. Направление без выбранных каналов остаётся пустым, включённое направление со значением 0 показывает 0. #mailing_addresses объединяет непустые адреса рассылки выбранных каналов без повторов (разделители в исходных полях — запятая, точка с запятой или перевод строки). В названии выводится только имя абонента; #transmission_designation на этом листе пуст, разделитель « / » перед ним удаляется автоматически. Категория абонента не ограничивает операторскую рассылку.

При расширении строк сдвигаются подписи и объединения, а диапазоны формул SUM и ссылки между листами обновляются. Для пустой группы сохраняется одна пустая оформленная строка, поэтому итог SUM возвращает 0. Формулы дат, включая TODAY(), сохраняются. Неизвестные метки или несколько групп в одной строке возвращают понятную ошибку шаблона. Печать всех вариантов использует тот же шаблон.

## Подписант статистики

В администрировании доступна единственная запись «Подписант статистики» с полями «Должность» и «Имя». После создания кнопка добавления скрывается; ограничение одной записи также действует на уровне базы. На сайте формы изменения нет. Для Excel-шаблона используйте #должность и #имя — отдельно в ячейке либо внутри текста. Пока подписант не заполнен, метки заменяются пустым текстом. Данные берутся из текущей записи при каждом скачивании.

Повторяющиеся адреса AFTN в одном файле объединяются до предпросмотра: «Принято» и «Передано» складываются, сохраняется одна запись канала за месяц. Названия каналов объединяются через « / », обозначение ПРД очищается, логический номер берётся из первой строки. Объединённое название обновляется также у существующего канала; имя абонента сохраняется. Каждая строка и итоговая сумма проходят проверку счётчиков. В AMHS повтор имени канала по-прежнему считается ошибкой. В предпросмотре AFTN после «Канал» показан столбец «ПРД» по центру; заголовок «Адрес» выровнен вправо.

Книга для экономистов использует тот же шаблон и правила расчёта, что «Скачать все», но включает только ECONOMIST_SHEETS из monthly_export.py. Имя: Статистика_месяц_год_для_экономистов.xlsx. Скачивание доступно за один выбранный месяц; фильтры отчёта сохраняются.

Печать «Центры - согласование» (?month=YYYY-MM&print=centers) доступна за один месяц с сохранением фильтров. monthly_export.py заполняет только лист «для согласования», printing.py переносит ячейки, размеры, объединения, шрифт, заливку, границы и настройки страницы в HTML. Автоматически открывается диалог печати; кнопка «Печать» позволяет вызвать его повторно. Исходный шаблон и база не изменяются. При печати поддерживается SUM по диапазону текущего листа для итогов; неподдерживаемые формулы и циклы возвращают ошибку шаблона.

«Абоненты - рассылка» (?month=YYYY-MM&print=subscribers) печатает только лист «для Оператора» с текущими флажками и суммами по абонентам, объединёнными адресами и рассчитанными итогами SUM. Печать открывается в новой вкладке, оформление и данные берутся из общего Excel-шаблона. Доступен один месяц, фильтры отчёта сохраняются.

Высота строк с данными сохраняется из шаблона, пока текст помещается в одну строку. При переносе длинного названия или адресов высота увеличивается по содержимому, но не уменьшается ниже заданной. Это единое правило для скачиваемых книг и браузерной печати.

«Каналы» (?print=channels) печатает «Каналы ПД», «ФГУП ГК», «Сторонние». «Распечатать все» (?print=all) печатает все листы шаблона в исходном порядке. Для пакета открывается одна вкладка и один диалог печати; каждый лист начинается с новой страницы и сохраняет свои параметры бумаги и боковых полей. Верхнее/нижнее поля — PRINT_VERTICAL_MARGIN_MM. При печати вычисляются SUM по диапазону листа и TODAY() в часовом поясе приложения; неизвестные формулы возвращают ошибку.
